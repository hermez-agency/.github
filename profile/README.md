**Hermez** is a digital agency that builds SaaS products, AI tools and open source libraries.
Every product below is *A Hermez product*. Learn more at [hermez.dev](https://hermez.dev).

## Products

- **[Ponos](https://the-ponos.app/)** — write the ticket, it comes back done: a self-hosted harness around Claude Code that runs your tasks on their own git worktree. ([source](https://github.com/hermez-agency/ponos))
- **[React Resource View](https://hermez.dev/react-resource-view/)** — CRUD views for JSON-LD / Hydra APIs: list, read, create, update and delete in table, card, calendar or timeline layouts. ([source](https://github.com/hermez-agency/react-resource-view))
- **[react-data-form](https://hermez.dev/react-data-form/)** — data-driven React forms with field controllers, groups and steps, designed for JSON-LD APIs / API Platform. ([source](https://github.com/hermez-agency/react-data-form))
- **[Leadz](https://leadz.ninja/)** — find and qualify leads in any industry.
- **[Whisper Desk](https://hermez.dev/whisper-desk/)** — offline voice dictation for Linux, WSL and macOS. ([source](https://github.com/SalvadorCardona/whisper-desk))
